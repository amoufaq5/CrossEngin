# R22 — docs/adr/ (358 files) and CLAUDE.md: documentation quality and truthfulness

## Summary (10 lines max)
- 355 ADRs + template (45,124 lines) and a 610 KB / 6,690-line CLAUDE.md. The docs are unusually candid: CLAUDE.md contains its own ranked defect register (9 P0, 17 P1, 15 P2) that is largely accurate where I checked (8/8 sampled items still true in code).
- The 13 foundational ADRs (all still "Proposed", all "Reviewers: _pending_") describe a different system from the one built: Inngest, OPA Rego, NextAuth, ClickHouse CDC, Prisma, React Flow, schema-per-tenant with `SET ROLE`, MFA, five LLM providers, HL7/EDI adapters. None of those exist in code. They were never superseded, so the ADR set is not a reliable description of the architecture.
- 14 packages (incl. `sso`, `compliance`, `active-active`, `security`, `data-lineage`) have zero importers — confirmed by grep. Multi-region, compliance packs, SSO, integration mesh, reporting are contracts-only.
- README.md and CONTRIBUTING.md are badly stale (README: "51 packages + 1 app, 5,768 tests"; CONTRIBUTING: "This repository holds architectural decisions, not code").
- CRITICAL side finding: the last commit on `origin/main` put what looks like a live Anthropic API key and a real Postgres password into `deploy/.env.example`.
- No CI, no `.github/`, no `SECURITY.md`, no ESLint config — all promised by ADR-0009.
- Single human committer, 303/355 ADRs "amoufaq5 (with AI assistance)", 43/50 visible commits carry Claude trailers; every ADR reviewer field is pending or self. Bus factor = 1 plus an LLM context file.
- CLAUDE.md is not usable as human onboarding: 243 KB "package map", 164 KB "what's left", written as increment-by-increment narrative it says it does not contain.

## Findings

### R22-01 [Critical] [CONFIRMED] [Secrets] Real-looking credentials committed to `deploy/.env.example` on `origin/main`
- Where: `deploy/.env.example:5`, `:13`, `:117`; commit `7bc8db9` (2026-10-14, "Modify .env.example with new Postgres and domain settings"); `git branch -a --contains 7bc8db9` lists `remotes/origin/main`.
- Evidence: line 117 holds an Anthropic-format API key beginning `sk-ant-usr-1…` (≈100 chars, replacing the placeholder `sk-ant-...`); line 5 `POSTGRES_PASSWORD=` holds a non-placeholder value beginning `Ams8…` (replaced `change-me-to-a-long-random-string`); line 13 a personal email at `crossengin.com`; `DOMAIN=crossengin.com`.
- Impact: if live, the API key is billable by anyone with repo access; the Postgres password plus the production domain is a direct path to the database if port 5432 is ever exposed. Contradicts ADR-0009 line 106 ("No secrets in repository. CI enforces via `gitleaks`").
- Fix: revoke/rotate both now; rewrite history or accept permanent exposure; add gitleaks pre-commit + CI.
- Effort: S (rotation), M (history + scanning)
- Not verifiable: whether the key is live (no network calls made).
